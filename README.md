# Estudos de Java

⚠️ Este é um repositório de **estudos e exercícios**, não um projeto de portfólio. Aqui ficam pequenos programas feitos para praticar conceitos de Java enquanto aprendo. Para projetos completos, veja os repositórios fixados no meu perfil.

## Conteúdo

O repositório reúne exercícios avulsos sobre:

Manipulação de arquivos e strings  
Programação Orientada a Objetos (encapsulamento, herança, polimorfismo)  
Sistemas simples de cadastro (alunos, funcionários, produtos, pedidos)  
Simulações de sistemas de pagamento e notificação  
Cálculos matemáticos simples (IMC, etc.)

## Tecnologias

Java puro, sem frameworks — cada pasta é um exercício independente.

## Observação

O código aqui prioriza a prática de conceitos específicos, não necessariamente segue as melhores práticas de arquitetura de um projeto real.
